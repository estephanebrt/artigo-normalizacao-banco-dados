# Normalização de Banco de Dados

## Sobre o projeto

Este projeto apresenta um artigo acadêmico sobre
normalização de banco de dados, explicando a
Primeira Forma Normal (1FN), a Segunda Forma
Normal (2FN) e a Terceira Forma Normal (3FN).

O objetivo é mostrar como a normalização ajuda
a organizar os dados, reduzir repetições e
evitar inconsistências.

## Arquivos do projeto

- index.html: página web do artigo.
- style.css: estilos visuais da página.
- exemplo.sql: exemplo de tabelas normalizadas.

## Tecnologias utilizadas

- HTML
- CSS
- SQL
